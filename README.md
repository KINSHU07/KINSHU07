## 🚀 Featured projects

### 🤖 Autonomous Lead Generation Agent
Built for Julio Hoyos & Company, a 30-year NJ accounting firm. A 6-step pipeline (scrape, deduplicate, rule-score, ICP-qualify, enrich, personalize) that runs every 6 hours.

- Ran 5+ days with zero manual intervention.
- Surfaced **101 high-priority leads from 1,400+ raw records** using a 0–100 rule scorer and a strict ICP qualifier.
- Delivered 471 qualified leads and ranked 1st among 6 competitors in the internship challenge.
- Includes a Streamlit dashboard and 11 industry-specific outreach emails.

`Python` `Playwright` `BeautifulSoup` `Streamlit` `Google Places API` `Foursquare` `n8n` `GCP Cloud Run` `Azure App Service`

### 📄 AI Due Diligence Copilot
A Retrieval-Augmented Generation platform for investment research where every claim carries a page-level source citation.

- Stores chunk text and its 768-dim embedding in one PostgreSQL + pgvector row, which avoids the index drift of file-based stores like FAISS.
- Runs on free APIs only, with exponential-backoff retry and a multi-model fallback chain on Hugging Face Inference.
- Alembic migrations, connection pooling, and a 15-test pytest suite run against a live pgvector instance.

`Python` `PostgreSQL` `pgvector` `SQLAlchemy` `Alembic` `Hugging Face` `PyMuPDF` `Streamlit` `GCP` `Azure`
